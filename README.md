# Gala Arq — Estudio de arquitectura

Portfolio súper minimalista para **Ana Gallela ("Gala")**, arquitecta.
Diseño propio en Figma. Referencia de estructura: https://diegoarraigada.com/es/

## Stack

| Capa | Herramienta |
|---|---|
| Framework | Next.js 16 (App Router, React Server Components) |
| Lenguaje | TypeScript |
| Estilos | Tailwind CSS v4 |
| Componentes | shadcn/ui |
| Estado de cliente | Zustand |
| CMS + dashboard | Sanity (Studio embebido en `/studio`) |
| Hosting y dominio | Cloudflare (Workers + Registrar/DNS) |

## Estructura

- `gala-arq-spec.md` — especificaciones del proyecto y contexto maestro. **Leer primero.**
